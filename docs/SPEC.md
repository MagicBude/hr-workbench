# 功能规格说明书（SPEC）

> 本文件定义每个模块的**详细行为规格**与**验收标准**，是开发实现的依据，也是测试验收的对照表。  
> 与 `docs/PLAN.md` 配套：PLAN 管"何时做"，SPEC 管"做成什么样"。

---

## 1. 花名册（Roster）

### 1.1 字段规格
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | string | 是 | `e_` + 时间戳，唯一 |
| name | string | 是 | 姓名 |
| dept | string | 否 | 部门 |
| hireDate | string(YYYY-MM-DD) | 否 | 入职日期 |
| baseSalary | number | 否 | 基本月薪（元） |
| restMinutes | number | 否 | 可调休余额（分钟，默认 0） |
| insuranceBase | number\|null | 否 | 社保基数，null=用 baseSalary |

### 1.2 行为规格
- **新增**：表单默认收起；填写姓名（必填）+ 部门/入职日期/基本月薪后保存。
- **编辑**：每行"编辑"按钮 → 弹窗修改全部字段（含可调休余额、社保基数）→ 保存即写回。
- **生命周期**：支持 `probation / active / suspended / departed`；离职归档保留历史，回收后可在设置中心恢复。
- **序号**：表格首列显示 `1,2,3...`，按数组顺序（= 拖拽后的顺序）。
- **拖拽排序**：行首拖拽手柄（≡），HTML5 Drag & Drop 交换数组元素，`persist()` 保存。
- **可调休余额展示**：编辑时按天/小时/分钟录入；显示格式可在设置中选择智能格式、总小时或天数小数。

### 1.3 验收
- [ ] 新增后序号自动递增。
- [ ] 编辑后刷新页面数据保留。
- [ ] 拖拽后顺序持久化。
- [ ] 旧数据（无 restMinutes）显示为 0 小时，不报错。

## 2. 考勤（Attendance）

### 2.1 数据结构
```
attendance: [{
  id: "a_{month}_{empId}",
  month: "2026-08",
  empId: "e_xxx",
  rec: { 1: { am:"√", pm:"√", ot:"" }, 2: {...}, ... },
  summary: { 出勤, 事假, 病假, 缺勤, 调休, 年假, 加班 }
}]
holidays: { "2026-01-01": { name:"元旦", type:"holiday" },
            "2026-02-11": { name:"春节调休上班", type:"workday" } }
settings: { overtimeToRest:true, overtimeToRestRatio:1.0, halfDayMinutes:240 }
```

### 2.2 时段与状态
- **三时段**：上午(am)、下午(pm)、加班(ot)。
- **状态循环**：工作日上午/下午在 `√ / 事 / 病 / 缺 / 调 / 年 / 迟 / 退 / 空` 中循环；加班行仅 `加 / 空`。

### 2.3 节假日规则
- `holiday`：视为休息日，默认不计入应出勤天数，格子灰色 + "休"标签。
- `workday`：调休上班日，计入应出勤，格子蓝色 + "班"标签。
- **可调**："节假日设置"弹窗可一键"重置为 2026 国家法定节假日"，也可手动增/删/改某天。

### 2.4 调休联动
- 选 `调` 且 `restMinutes >= halfDayMinutes` → 扣减半天；不足则提示剩余不足。
- 上午或下午各计 `halfDayMinutes`；全天计 `2*halfDayMinutes`。
- 选 `加` 且 `settings.overtimeToRest=true` → 按 `overtimeToRestRatio` 增加 `restMinutes`（加班时段计 `halfDayMinutes * ratio`）。

### 2.5 表头与视觉
- 表头两行：第 1 行日期(1–31)，第 2 行星期（一/二/.../日）。
- 周末列浅色背景区分；节假日列特殊标记。
- 右侧汇总列：出勤天数、事假、病假、缺勤、调休、年假、加班小时。
- 风格参考用户原始 Excel 截图：蓝紫表头、白底日期格、清晰网格线。

### 2.6 验收
- [ ] 2026-01-01/02 自动显示节假日。
- [ ] 每员工每天可独立设上午/下午/加班。
- [ ] 旧 `rec` 自动升级为分时段。
- [ ] 选调休扣减余额，不足提示。
- [ ] 选加班（开启时）增加余额。
- [ ] 表头显示正确星期，周末浅色。

## 3. 薪资（Payroll）

### 3.1 字段
```
payroll: [{
  id, month, empId,
  baseSalary, travel, bonus, overtime,
  comp: { 养老, 医疗, 工伤, 失业, 生育, 公积金 },   // 公司缴纳
  pers: { 养老, 医疗, 失业, 公积金, 大病医疗 },     // 个人缴纳
  gross, persTotal, tax, net,
  taxManual: false,
  status: "draft"|"confirmed"|"paid"
}]
```

### 3.2 计算口径
- 基数 `base = employee.insuranceBase || payroll.baseSalary`。
- `comp.x = base * ratio.company.x`；`pers.x = base * ratio.personal.x`。
- `gross = base + travel + bonus + overtime`。
- `persTotal = Σ pers`。
- `tax`：演示用 `(gross - persTotal - 5000) * 10%`，可手动覆盖。
- 收入变化会重算未人工覆盖的税额；手工修改后标记 `taxManual=true`。
- 已确认和已发放记录锁定收入项与税额输入。
- `net = gross - persTotal - tax`。

### 3.3 比例设置
- 组织默认比例在 `settings.insuranceRatio`（初始值见 `config.js`）。
- "社保公积金比例设置"弹窗可改组织比例（6 公司项 + 5 个人项 + 大病医疗固定额）。
- 员工级覆盖：员工 `insuranceBase` 非 null 时，按该基数计算，其余人用 baseSalary。

### 3.4 展示
- 表头双层：主分组「公司缴纳」「个人缴纳」，子列具体项目。
- 每行展示应发、个人五险一金合计、个税、实发（绿色高亮）。

### 3.5 验收
- [ ] 公司/个人缴纳各分项可见。
- [ ] 改组织比例后刷新即重算。
- [ ] 员工社保基数覆盖生效。
- [ ] 旧数据用默认比例，结果不变。

## 4. 看板（Dashboard）

- 出勤率口径：`实际出勤分钟 ÷ 应出勤分钟`；应出勤按工作日、节假日覆盖及员工入离职区间计算。
- 当前月份只统计截至当天的应出勤，不把未来工作日标记为未录入。
- 同时区分应出勤、实际出勤、请假、缺勤和未录入。
- 出勤率环形图（内联 SVG）。
- 工资趋势折线图（按月份，内联 SVG）。
- Phase 9 增加：人力成本趋势、离职率、异常考勤预警。

## 5. 导入 / 导出

### 5.1 导入（JSON）
- 格式：`{ org:{id,name}, data:{ employees, attendance, payroll, holidays?, settings? } }`。
- 行为：覆盖**当前组织**全部数据。导入前提示确认。
- 兼容：导入后由 `store.js` 迁移函数补全新字段。

### 5.2 导出（JSON）
- 完整备份当前组织数据，含 `version` 字段（Phase 8）。

### 5.3 导出（Excel，Phase 4）
- 花名册 `.xlsx`：序号、姓名、部门、入职日期、基本月薪、可调休、社保基数。
- 考勤 `.xlsx`：表头含日期+星期，每人每天三行（上/下/加），右侧汇总。
- 薪资 `.xlsx`：姓名、入职日期、薪资起止、考勤(出勤/缺勤/实出)、出差补贴、奖金、基本月薪、节假日加班费、本月应发、公司缴纳(6项)、个人应缴(5项)、应补退税额、实发。
- 技术：本地 `vendor/xlsx.mini.min.js`，零 CDN。

## 6. 远期模块规格（Phase 6–10，概要）

| 模块 | 核心规格 |
|---|---|
| 权限 RBAC | 角色：超级管理员/HR/部门经理/员工自助；员工自助仅见自己数据；改薪资二次确认 |
| 审批流 | 调休/请假/加班/薪资发放走状态机：草稿→待审批→通过/驳回→撤销 |
| 审计日志 | 记录操作人、时间、对象、前后值；支持按模块/时间检索 |
| BI 预警 | 出勤率<80% 或连续缺勤3天标红；人力成本环比>10% 提醒 |
| 多币种 | 员工 `currency` 字段；按汇率折算本位币汇总 |
| 合同管理 | 合同起止、续签提醒、附件（占位） |
| 异动流程 | 入职/转正/调岗/离职记录时间线 |
| PWA | manifest + service worker，离线可用、可"添加到主屏" |
| 集团版 | 多组织汇总看板，按组织/部门下钻 |
| 开放接口 | `importAttendance` / `exportToFinance` 适配器，便于对接外部系统 |

## 7. 通用交互规格

- 弹窗：Enter 保存、Esc 关闭、点遮罩关闭。
- 空状态：每个模块无数据时显示友好提示 + 操作按钮。
- 移动端：输入框≥44px，表格横向滚动，底部 Tab 在安全区内。
- 性能：50 员工 × 12 月数据下，Tab 切换无明显卡顿。
